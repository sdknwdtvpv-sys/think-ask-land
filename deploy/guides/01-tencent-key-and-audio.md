# 01 · 腾讯云密钥与预置音频生成

> **一句话**：让"答对了,真棒"、字卡里的字词句，全部用**智小虎**的声音念出来，并且离线、加到主屏幕也一定响。
>
> **耗时**：第一次约 20 分钟（其中大半是在腾讯云注册实名）；以后再补音频约 5 分钟。
>
> **需要准备**：一台电脑、一个手机号（或微信号）、身份证（腾讯云实名用）。
>
> **做完你会看到**：`python3 .build/gen-audio.py --check` 显示 `1533/1533`，并且线上点读时能听到智小虎。

---

## ⭐ 最省事的做法：一条命令走完全程（推荐）

**如果你已经有密钥了**（刚新建的也算），直接粘贴这一行，然后照着屏幕提示走：

```bash
bash "/Volumes/Elliot's SSD/HARNESS/hanzi-kids/.build/run-audio.sh"
```

它会依次做 5 件事，每一步都会告诉你"现在在做什么、看到什么算对"：

1. 检查现在缺多少条
2. 让你粘贴密钥（**输入时不显示，也不会留在命令历史里**）
3. 先生成 3 个字 + 10 句口播，**自动打开访达让你试听**
4. 你听完输入 `y` 才继续补齐全部（不好听就输入 `n` 停下，告诉我，我给你换音色）
5. 补齐 → 自动校验 → 问你要不要直接上线

出错了也不用慌：它会把腾讯云的英文报错翻成中文，并告诉你下一步点哪里。

> 下面第 0~9 步是**手动版**，内容和向导一样，适合你想知道每一步到底在干什么，或者向导跑不通时照着排查。

---

## 第 0 步：先确认"是不是真的需要做"

在电脑上打开「终端」（Terminal），粘贴这一行并回车：

```bash
cd "/Volumes/Elliot's SSD/HARNESS/hanzi-kids" && python3 .build/gen-audio.py --check
```

- 如果最后显示 **`✅ 覆盖完整`** → 不需要做，关掉即可。
- 如果显示 **`⚠️ 覆盖 1205/1533 缺 328 条`** → 继续往下做。
- 如果提示 `command not found: python3` → 发我截图，我换个方式给你命令。

---

## 第 1 步：注册 / 登录腾讯云（约 5 分钟）

1. 浏览器打开 **https://cloud.tencent.com**
2. 右上角点 **「登录」** → 选择 **微信扫码**（最省事）
3. 登录后如果弹出"实名认证"，点 **「去认证」**：
   - 选 **个人认证**
   - 填姓名 + 身份证号 → 用微信/QQ 扫脸
   - **看到"实名认证成功"或"已认证"就算完成**

> 找不到入口？点右上角**头像** → 菜单里就有 **「实名认证」**。

---

## 第 2 步：开通"语音合成"服务（约 2 分钟）

1. 打开 **https://console.cloud.tencent.com/tts**
2. 页面中间如果有 **「立即开通」**（或「开通服务」）按钮 → 点它
3. 弹窗里勾选 **同意服务协议** → 点 **「确认开通」**
4. **看到"语音合成"的控制台页面（左侧有菜单、顶部有"概览"）就算成功**

> 找不到？在腾讯云控制台顶部的搜索框输入 **`语音合成`**，点搜索结果里的产品即可。

---

## 第 3 步：领免费额度（约 1 分钟，必做）

**不领这一步，就会按量扣钱**（虽然我们只用两千多个字，也就几分钱，但领了省心）。

1. 打开 **https://console.cloud.tencent.com/tts/resourcebundle**
2. 找到 **「基础/精品音色」免费资源包**（800 万字符那个）
3. 点 **「领取」** → 确认
4. **看到资源包列表里出现一条有效期 3 个月的记录就算成功**

---

## 第 4 步：创建 API 密钥（约 2 分钟）——**这一步的东西不要发给任何人**

1. 打开 **https://console.cloud.tencent.com/cam/capi**
   （路径：控制台右上角头像 → **访问管理** → 左侧 **访问密钥** → **API 密钥管理**）
2. 点 **「新建密钥」** → 可能会要求微信扫码确认 → 确认
3. 列表里会多出一行，包含两串字符：
   - **SecretId**：以 `AKID` 开头
   - **SecretKey**：一串字母数字（**点"显示"才看得到**）
4. **先别关这个页面**，下一步要用。

> ⚠️ 这两串就是"取用腾讯云服务的钥匙"。**不要发给我、不要发到任何群里、不要写进代码文件。**
> 如果担心，做完第 8 步可以在同一个页面把它 **禁用** 或 **删除**。

---

## 第 5 步：在终端里设置密钥（约 1 分钟）

打开「终端」，**把下面两行里的中文部分替换成你刚复制的两串**，然后粘贴回车：

```bash
export TENCENT_SECRET_ID=把这里换成你的SecretId
export TENCENT_SECRET_KEY=把这里换成你的SecretKey
```

**验证一下有没有设对**（应该各自打印出一串字符）：

```bash
echo $TENCENT_SECRET_ID
echo $TENCENT_SECRET_KEY
```

> ⚠️ 这两行只对**当前这个终端窗口**有效。**关掉终端就要重设一次**，所以请一口气做完下面几步。

---

## 第 6 步：先试听（约 1 分钟，强烈建议）

```bash
cd "/Volumes/Elliot's SSD/HARNESS/hanzi-kids"
python3 .build/gen-audio.py --engine tencent --voice "502007:tc-502007:智小虎" --only 今,夜,羞 --trim
```

跑完后**打开试听文件夹**（会自动弹出访达窗口）：

```bash
open audio/tc-502007/p     # 口播:答对了,真棒 等 10 句
open audio/tc-502007/z     # 单字:今 / 夜 / 羞
```

**听到满意的声音 → 继续第 7 步。觉得不好听 → 停在这里告诉我**，我给你换音色的命令（腾讯云有别的音色可选）。

> 如果提示 `未找到 ffmpeg，--trim 忽略` → 不影响，可以继续（只是文件略大一点）。

---

## 第 7 步：正式补齐（约 2~5 分钟）

```bash
cd "/Volumes/Elliot's SSD/HARNESS/hanzi-kids"
python3 .build/gen-audio.py --engine tencent \
    --voice "502007:tc-502007:智小虎,403000:tc-403000:云小朵" --resume --trim --concurrency 6
```

- 屏幕上会一行行往下跑，最后显示 **`完成：本次生成 2 个音色…`**
- **中途断了不要紧**：重新粘贴同一条命令，它会自动跳过已经生成的（`--resume`）。

---

## 第 8 步：确认成功

```bash
python3 .build/gen-audio.py --check
```

**看到 `✅ 覆盖完整` 或 `1533/1533` 就是成功。**

到这里，腾讯云的密钥已经不需要了。可以回到第 4 步的页面把它 **禁用**（推荐）：

> https://console.cloud.tencent.com/cam/capi → 找到那行 → 点 **「禁用」** → 确认。
> 下次要再生成音频时，重新 **启用** 或新建一个即可。

---

## 第 9 步：上线（约 3 分钟）

```bash
cd "/Volumes/Elliot's SSD/HARNESS/hanzi-kids"
./deploy/release.sh "补齐预置朗读音频(84 个新字 + 10 句口播)"
```

看到 **`🎉 服务器部署验收全部通过`** 就完成了。之后在手机上打开 https://hanzi.elliotli.work ，点几个字听听，应该已经是智小虎的声音。

## 出错了怎么办

| 屏幕上出现的字样 | 意思 | 怎么办 |
|---|---|---|
| `AuthFailure.SignatureFailure` | 密钥复制错了（多了空格/换行） | 重新复制 SecretId / SecretKey，注意**不要带前后空格**，再跑第 5 步 |
| `AuthFailure.SecretIdNotFound` | 这串 SecretId 不存在 | 密钥可能被删了，回第 4 步重新建一个 |
| `FailedOperation` / 提到"欠费""额度" | 免费额度没领或已用完 | 回第 3 步领额度；或在该页面开通后付费（我们只用几千字符，费用可忽略） |
| `RequestLimitExceeded` | 请求太密 | 把命令里的 `--concurrency 6` 改成 `--concurrency 2` 再跑 |
| `command not found: python3` | 没装 Python | 发我截图，我给你另一条命令 |
| `未找到 ffmpeg` | 少了去静音的小工具 | 可以忽略；或运行 `pip3 install imageio-ffmpeg` |
| 跑到一半断了 | 网络波动 | **重新粘贴同一条命令**即可，会自动跳过已生成的 |
| 其它看不懂的红色报错 | — | **把报错整段复制给我**（红色文字即可，密钥不会显示在里面） |
