# 08 · 装到真机上（iPhone / iPad）

> **一句话**：把思问岛装到你的手机上，实际摸一遍。
>
> **需要**：一部 iPhone 或 iPad + 一根数据线 + **一个 Apple ID**。
> 🔑 **不需要 99 美元的开发者账号** —— 免费的「个人团队」就能装。
>
> **耗时**：首次约 15 分钟（含下载与首次签名）。
>
> **能做到什么**：整个 App 的功能都能试 —— 字卡、笔顺、朗读、录音、家长门、拼音、说一说。
> **做不到什么**：**真实内购**（那需要付费账号 + App Store Connect 商品）。
> 但内购流程可以用 Xcode 的 **StoreKit 配置**在本地跑通（见第四节）。

---

## 一、先说清楚「免费个人团队」的代价

用普通 Apple ID 登录 Xcode，会得到一个 **Personal Team**（个人团队）。够用，但有三条限制：

| 限制 | 具体 | 影响我们吗 |
|---|---|---|
| **描述文件 7 天过期** | 7 天后 App 打不开，重连电脑 Run 一次即可续期 | ⚠️ 每 7 天要插一次线 |
| 最多 3 个 App / 10 个 App ID | 每 7 天 | 不影响 |
| 不能用推送、iCloud、Game Center 等能力 | — | ✅ **我们一个都不用** |

> 我们是**完全离线、无推送、无 iCloud、无账号**的 App，所以免费团队的限制几乎不碰。

## 二、五步装到手机上

### ① 插上手机、信任这台电脑

1. 用数据线把 iPhone 插到 Mac
2. iPhone 上会弹「**要信任此电脑吗？**」→ 点 **信任**，并输入手机密码
3. 如果没弹：拔了重插；或 iPhone 上 `设置 → 通用 → 传输或还原 iPhone → 还原 → 还原位置与隐私`

**做完你会看到**：Xcode 顶部设备列表里出现你的手机名字
（也可以先跑这条确认：`xcrun devicectl list devices`，真机那行的 `Reality` 应显示 `physical`）。

### ② 在 Xcode 里登录你的 Apple ID

1. 打开 `ios/App/App.xcodeproj`
2. 菜单 **Xcode → Settings…**（快捷键 `⌘,`）→ **Accounts** 标签
3. 左下角 **`+`** → **Apple ID** → 登录
4. 登录后，右侧会列出 **Personal Team**，记下它的名字（通常是你的名字）

> ⚠️ 如果登录后**没有** Personal Team：说明这个 Apple ID 已经是某个付费团队的成员了，
> 那就用那个团队；或者换一个 Apple ID。

### ③ 给工程选上团队

1. Xcode 左侧点最上面的蓝色工程图标 **App**
2. **TARGETS → App → Signing & Capabilities** 标签
3. 勾上 **Automatically manage signing**
4. **Team** 下拉框选你刚才的 Personal Team
5. 如果 **Bundle Identifier** 那一行变红报冲突：
   把 `work.elliotli.siwendao` 改成别的唯一值（比如后面加你的名字缩写）
   —— **只为了本地试装，不影响以后的正式包**

**做完你会看到**：Bundle Identifier 变黑、下面出现一行绿色的
`Signing Certificate: Apple Development: 你的邮箱`。

> 💡 第 ⑤ 步改的 Bundle ID 只在这台机器上，**不会影响仓库里原来的值**
> （除非你存盘提交）。试完想还原：`git checkout ios/App/App.xcodeproj`。

### ④ 选设备，Run

1. Xcode 顶部中间的设备下拉框 → 选**你的手机**
2. 按 **▶︎**（或 `⌘R`）
3. 首次会编译并安装，手机上出现「思问岛」图标

### ⑤ 手机上信任开发者证书（首次必做）

装完直接点图标会提示「**未受信任的开发者**」。去：

**iPhone → 设置 → 通用 → VPN与设备管理 → 开发者App → 你的 Apple ID → 信任**

然后再点图标就能打开了。

## 三、装在手机上之后，重点验这几件事

这些是**模拟器验不了**的（我在模拟器上跑了一路，真机差异主要在这里）：

### C1 音频（最重要）

| 试什么 | 为什么模拟器不算 | 期望 |
|---|---|---|
| 点字卡的字，听有没有声音 | 模拟器音频路由和真机不同 | 字音清晰、不延迟 |
| **把手机侧边的静音拨杆拨到静音**，再点读 | 真机才会暴露"家长以为没声音" | 确认是否有声音（**这一条要如实记录**） |
| 点开「读一读」连读一段 | 连读链条最容易断 | 一句接一句不断 |
| 音量键调大调小 | — | 正常 |

> 📌 **为什么特别关注静音键**：App 目前没有配置 AVAudioSession。
> 若静音键拨下后完全没声，家长很可能以为"App 坏了"，
> 需要在 `AppDelegate.swift` 里加一段音频会话配置（我可以做）。

### C2 录音权限

1. 「说一说」里点录音 / 字卡里点跟读
2. 应弹出权限框，文案是：**「用于录制孩子的跟读发音，在家长陪同下即时回放比对。录音只保存在本机，不会上传，也不会留存。」**
3. 允许 → 录一段 → 回放
4. **再试一次"拒绝"**：确认拒绝授权后其它功能照常（不该崩、不该卡）

### C3 进度是否保留（覆盖安装）

1. 学几个字，记下进度
2. **不要删 App**，用 Xcode 再 Run 一次（覆盖安装）
3. 看进度还在不在

> 这一条我在设计上做了保护（进度落在原生 Preferences，不受 WebView 存储淘汰影响），
> 但 **Apple 没有一手说明"App 更新是否保留 WKWebView 存储"**，所以只能实测。

### C4 家长门

点「家长中心」→ 应出现一道**两位数乘法**并朗读「这道题请家长来完成」。
连着答错 3 次 → 应锁 10 秒。

### C5 性能

笔顺动画是否流畅、"趣味练习"切题是否卡顿。老设备上更能看出来。

## 四、想在真机上看到内购流程（可选，10 分钟）

真实内购需要付费账号 + App Store Connect 商品。但 Xcode 提供了**本地 StoreKit 配置**，
让你不花一分钱就能把「点购买 → 弹窗 → 购买成功 → 内容解锁」整条路走通。

1. Xcode 菜单 **File → New → File…**（`⌘N`）
2. 搜索 **StoreKit Configuration File** → Next → 命名如 `Siwendao` → 存到 `ios/App/`
3. 打开它，左下角 **`+`** → **Add Non-Consumable**
4. 填：
   - **Reference Name**：`完整内容解锁`
   - **Product ID**：`work.elliotli.siwendao.full_unlock`
   ⚠️ **必须一字不差** —— 它写死在 `js/entitlements.js` 的 `PRODUCT_ID`
   - **Price**：随便填（本地测试用）
5. 菜单 **Product → Scheme → Edit Scheme…** → 左侧 **Run** → **Options** 标签
   → **StoreKit Configuration** 选刚才那个文件
6. 重新 Run，进「家长中心」→ 输入乘法答案 → 拉到底部「完整内容」→ 点解锁

**做完你会看到**：出现真实的 App Store 购买弹窗（本地模拟），确认后内容立即解锁。

## 五、出错了怎么办

| 现象 | 意思 | 怎么办 |
|---|---|---|
| Xcode 设备列表里没有手机 | 没信任 / 线是充电线 | 拔插重试；换一根**数据线**；`设置 → 通用 → 传输或还原 → 还原位置与隐私` |
| `Signing for "App" requires a development team` | 第 ③ 步没做 | 回去选 Team |
| `Failed to register bundle identifier` | Bundle ID 被别人占了 | 按第 ③ 步最后一条改成唯一值 |
| `Untrusted Developer` | 第 ⑤ 步没做 | 手机设置里信任证书 |
| 装上了但 7 天后打不开 | 免费团队描述文件过期 | 插上电脑重新 Run 一次 |
| `Unable to install… device is locked` | 手机锁屏了 | 解锁手机再 Run |
| 编译报错但不说是哪 | 缓存 | Xcode `Product → Clean Build Folder`（`⇧⌘K`）后重试 |

## 附：为什么 Mac 上必须插线

模拟器（`simulated`）和真机（`physical`）是两条完全不同的路：

| | 模拟器 | 真机 |
|---|---|---|
| 签名 | 不需要 | **必须**（团队 + 描述文件） |
| 音频路由 | 走 Mac | 走手机（含静音键） |
| 麦克风 | 走 Mac 的麦克风 | 走手机，且**会弹权限框** |
| 性能 | Mac 的 CPU | 手机的 CPU（老设备差别明显） |
| 内购 | 需 StoreKit 配置 | 需 StoreKit 配置，或真实商品 |
