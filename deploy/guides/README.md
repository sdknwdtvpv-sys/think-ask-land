# 操作指南 · 目录与约定

> 约定：**凡是"需要你在电脑/手机上做几步操作、中间可能出错的"事情，我都会在这里放一份照着点就行的指南。**
> 每份指南的结构固定：目标 → 要准备什么 → 一步步点哪里 → 复制粘贴的命令 → 出错了怎么办 → 怎么确认成功。

|---|---|---|---|

| 02 | [发版上线与回滚](02-release-and-rollback.md) | 改完东西要发布到线上，或线上出问题要回滚 | 3~6 分钟 |

## 你需要知道的三件事

1. **不用担心做错**：指南里每一步都写了"看到什么算对"。不确定就停下来，把屏幕上看到的内容发我。
2. **密钥永远不要发给我**（也不要发到任何聊天里）。指南里会给"怎么用、用完怎么关掉"。
3. **所有操作都可以重来**：音频生成中断了重跑同一条命令即可（会自动跳过已生成的）；上线出问题可以一条命令回滚。
